# CodeAlpha Stock Trading Platform

This project is developed as **Task 2** of my **CodeAlpha Java Programming Internship**.

## 📌 About the Project

The **Stock Trading Platform** is a simple Java-based application that allows users to buy and sell stocks, manage their portfolio, and view transaction history.

The project was developed to practice Java programming and Object-Oriented Programming concepts.

## ✨ Features

- View available stocks
- Buy stocks
- Sell stocks
- Track portfolio
- View transaction history
- File handling
- Menu-based interaction

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming
- File Handling
- VS Code

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code or any Java-supported IDE.
3. Compile `StockTradingPlatform.java`.
4. Run the program.
5. Follow the instructions displayed in the console.
